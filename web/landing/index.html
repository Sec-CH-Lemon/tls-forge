01 / THE PROBLEM

A User-Agent is
only one signal.

Before a server reads an HTTP header, it has already seen the TLS handshake. Standard Go, Node.js and Python clients expose network behavior that can disagree with a browser User-Agent.

TLS Forge starts with a measured browser profile and carries its TLS choices, HTTP settings, ordered headers and policy together.

03 / THE WORKFLOW

From observation
to a repeatable request.

A local measurement loop connects what the browser sent to what your code sends.

  1. 01

    Observe a browser

    capture records the raw ClientHello and HTTP behavior through a local echo server.

  2. 02

    Store the profile

    Keep captured fields and explicit generation rules in a versioned JSON profile.

  3. 03

    Send from your stack

    Select the profile in the CLI, proxy or an SDK. The transport rebuilds dynamic values for each connection.

  4. 04

    Compare the result

    compare reports structural differences, so a hash mismatch has something concrete behind it.

A CLEAR SCOPE

Network behavior,
with honest limits.

TLS Forge models browser networking; it does not launch a browser, execute page JavaScript, load subresources or solve managed challenges and CAPTCHAs. Host TCP/IP behavior still comes from your operating system. HTTP/3 fidelity depends on the selected profile and remains an active area of work.

05 / COMMON QUESTIONS

Before you
forge a request.

Do I need Chrome to make requests?

No. Fetching, proxying and the language SDKs do not require a browser. A Chromium-based browser is needed for local capture and comparison.

Can changing a User-Agent do the same thing?

No. A server can also observe the TLS handshake, HTTP/2 settings and header order. TLS Forge keeps these choices together in a profile.

Does a matching fingerprint guarantee access?

No. Sites can use JavaScript challenges, cookies, behavior and other signals. TLS Forge addresses the network fingerprint, not every access control.

How do I check a profile?

Run tls-forge compare with a Chromium-based browser installed. It measures both sides locally and reports the fields it can compare.
