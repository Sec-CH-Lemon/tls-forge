## F06: JSON и движок

Три выбора перенесены из Go literals в JSON всех18 shipped profiles и двух
явных catalogue templates. Они передаются до production HTTPS DNS query:

| Поле | Перенесённое значение | Границы |
| --- | --- | --- |
| dns.https_query_recursion_desired | true | bool |
| dns.https_query_udp_payload_bytes | 4096 | integer512..65535 |
| dns.https_query_timeout_ms | 2000 | integer1..60000ms |

Это исходные продуктовые choices. Их перенос не устанавливает DNS parity всех
исторических browser/platform profiles. [Происхождение и before/after hashes](../../../profile/provenance/a12-dns.json)
отделены от original capture provenance. Исходные browser/capture/basis hashes
155/156 сохранены; текущие profile hashes и история преобразований обновлены.

Registry отвергает неизвестные/повторные/неверно типизированные/null/out-of-range
значения и неполную группу. Execution loader требует все три до I/O. Offline
Inspect/Save/Clone сохраняют отсутствие всей группы; только явный Migrate
создаёт отдельного кандидата из закреплённых JSON migration data.

Per-server timer общий для UDP и TC→TCP. Следующий server получает свой budget,
но request cancellation/deadline ограничивает все exchanges. Старые wait_percent/
min/max остаются отдельным ожиданием HTTPS после A/AAAA; budgets не складываются
повторно. Query ID генерируется для текущей транзакции; wrong-ID не вызывает TCP.

Plain HTTP discovery больше не теряет уже полученные A/AAAA: bounded handoff
принадлежит одному request chain, потребляется actual connection один раз и
сохраняется только для немедленного synthetic HTTPS redirect. Другой hop/restart,
host/port и независимый Do его не наследуют. Ошибка resolution передаётся без
повторного сетевого запроса. Используется существующий resolved-name resolver,
который сохраняет Go dial/Happy Eyeballs mechanism; TTL address cache не добавлен.

## Доказательства до и после

- Исходные project/fork tar archives сняты до изменений. Для duplicate lookup
  использован действительный New с shipped request scope, по два независимых Do.
  До исправления plain HTTP дал A4/AAAA4/HTTPS4, DNS-upgrade A4/AAAA4/HTTPS2;
  после — по2 каждого типа. Старый workflow helper с client scope не считается
  доказательством default isolation и сохранён только как диагностический запуск.
- Собственный UDP/TCP observer сохраняет original query bytes. Он не получает
  ожидаемые policy values: ответы задают owned addresses/records. JSON-only
  variants RD=false/true, EDNS512/1232/65535 и40/160ms видны на actual wire/timer.
- Проверены foreign ID, truncation/TCP framing, cancellation после actual UDP
  и TCP phase с закрытием реального сокета, expired context без traffic,
  per-server40ms против parent15ms и concurrent client policies. Save/Load/Clone,
  explicit migration и malformed policy проходят отдельные pre-I/O controls.
- Первоначальный per-test dial-hook teardown дал DATA RACE. Этот RED сохранён;
  fixture observer теперь установлен до старта тестов и выбирается private
  context value, без racing replacement/reset. Требования actual Close и сроков
  сохранены. Новая20race когорта PASS37.640s.
- Семь production mutants отвергнуты assertions: hardcoded RD/payload/timeout,
  потеря address handoff, принятие чужого ID, отсутствие TCP fallback и
  отсутствие socket cancellation. После каждого восстановлены исходные bytes.

## Наблюдения Chrome

Chrome156.0.8078.76/macOS, два независимых headed запуска с новыми пустыми
профилями; secure DoH на собственный loopback resolver, H2/TLS origin рядом.
Каждый запуск: шесть навигаций к двум именам, successive requests, forced close
и resumed connection. Original DNS/NetLog/CDP/connection sequence сохранены.
Favicon/background queries также сохранены, не выдаются за целевые samples.

Четыре HTTPS queries к owned именам имеют RD=true/EDNS4096. Отдельные20 actual
product UDP observations с default JSON имеют те же два поля. Байт-в-байт
равенство между разными transport contexts не объявляется: Chrome DoH ID0 и
OPT padding до128 bytes сохраняются как отдельные свойства; product UDP ID
генерируется и padding отсутствует. Имена и non-default port request-derived.

В обеих NetLogs IPv6 reachability check сообщает false, AAAA отсутствуют.
Это наблюдение данного Mac/path; оно не переносится на Linux/Windows.
Chrome сохраняет DNS result между соединениями: этот F06 не реализует полный
Chrome address cache/DoH/IPv6 selection. Дополнительный outer sandbox-exec
не позволил Chrome инициализировать native sandbox; неудачный запуск сохранён
как отказ среды. Принятые когорты сохраняют собственную sandbox Chrome и
перечень startup flags; external traffic не объявляется firewall-isolated.
