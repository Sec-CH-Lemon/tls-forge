# A4: ручной захват и секреты

Ветка `codex/a0-p0-remediation`; исходная точка `3f73a07a`.
Выполнены S07 → S08 утверждённого плана. A5 не начинался.

Профильные JSON и исходные измерения браузеров не изменялись.

## S07

- Идентификатор файла: `[a-z0-9][a-z0-9_.-]*`, без `..`.
  В major браузера входят только1–4 ASCII цифры; некорректная версия
  не становится компонентом имени.
- Пакет profile владеет раскладкой version/platform. Чтение каталога и
  атомарная запись используют os.Root: выход через символическую ссылку
  запрещён, в том числе при замене родительского каталога.
- Неявное имя ручного захвата — `manual_<browser>_<major>`. Просто запретить
  `local` недостаточно: посетитель мог объявить `chrome_9999` и изменить
  выбор newest family. Явный `--name` остаётся решением владельца CLI.
- Навигации получают128 случайных бит; каждый endpoint сверяет remote host
  и User-Agent до изменения отчёта, завершения захвата или состояния tickets.
  Сохранены новые соединения того же посетителя и отдельный визит HTTP/1.1.
  Тестовые браузеры теперь держат один сетевой User-Agent: Go по умолчанию
  называл себя по-разному в H1/H2 и при ручных запросах.

Коммит основного модуля `0215efd`. До исправления регрессии воспроизводили
небезопасные имена, запись через ссылку наружу и чужие collect/skip/hello.
После — все затронутые пакеты прошли свежий полный прогон с100% покрытия.
[Манифест S07](a4/s07-checks.json) сохраняет команды, ограничения и хэши.

## S08

utls `18ad370` пишет ключи исключительно в явно заданный KeyLogWriter.
SSLKEYLOGFILE не читается ни клиентом, ни сервером: существующий файл остаётся
неизменённым, недоступный путь не ломает TLS1.2/1.3. Явные writers сохраняют
ошибки записи и освобождение mutex. Полный utls race suite проходит.
Node/Python исключают только эту переменную, без учёта регистра, при каждом
старте и замене daemon. Остальные QUIC-переменные и GODEBUG, как и окружение
родительского процесса, сохранены. Проверен restart с обязательным SessionReset.

QUIC `91882e21` даёт существующему JSON quic.initial_layout приоритет над
QUIC_GO_DISABLE_CLIENTHELLO_SCRAMBLING. До исправления env=true отменял
scramble. Production regression расшифровывает фактические UDP Initial,
проверяет пропуск/последующее заполнение диапазонов и полный ClientHello,
а не число CRYPTO в первом пакете: оно зависит от extension order.
Три повтора для каждого значения env: до исправления3 отказа true и3 успеха
false, после6 успехов. Исходные datagrams и policy сохранены. Никакие ключи
или случайные значения в production JSON не перенесены. GODEBUG=http2client=0
проверен через фактический профильный HTTP/2 запрос; выбор профиля сохранён.
ECN/GSO остаются ограничениями доступных host I/O facilities, документируются
как часть окружения измерения; тесты macOS не доказывают поведение Linux.

Диагностический redact скрывает X-Auth/X-Authorization целиком, именованные
секретные query-параметры (повторяющиеся и percent-encoded имена тоже), URL
пароли в Validate/CanonicalURL/OwnPage/CookiesFor и final URL отчётов.
CanonicalURL сохраняет форму Unwrap к причине; ошибки сохраняют errors.Is/As.
Успешный CanonicalURL, запросы и application payloads не цензурируются.

Pcap snapshot собирает исходящие байты TCP перед маскированием, затем
возвращает те же event cuts и длины. Proxy-Authorization скрывается в каждом
открытом H1 request head, включая несколько запросов на одном соединении.
HTTP framing parser пропускает тела Content-Length/chunked; после CONNECT
туннель не интерпретируется как новая proxy head. Контроли сохраняют тела,
TLS/binary и исходные буферы, проверяют каждый префикс и запись по одному байту.

Расширенная TestAProxysPasswordIsWrittenNowhere проверяет реальные API,
CLI stdout/stderr, логи/trace/report, pcap и ambient keylog. Сохранены полные
артефакты до/после. Независимый tshark подтверждает4 forward pcaps:
по1 и2 запросам на одном TCP stream в каждом состоянии. До —2 файла
с исходным Basic; после —0. Длины credentials сохранены. Первый тестовый
прокси закрывал соединение: его исходные файлы сохранены отдельно, а reuse
подтверждён повтором с постоянным прокси и явным счётчиком соединений.

## Ограничения

- Это закрытие S07/S08, не доказательство неотличимости от Chrome. Нового
  Chrome actor здесь нет; историческая браузерная приёмка не перенесена
  на все версии/платформы или на новый runtime.
- Visitor = remote host + User-Agent. Знание токена при совпадающем visitor
  остаётся bearer-доступом; сервер не аутентифицирует человека/браузер.
  Конечный набор токенов не доказывает качество RNG.
- Явные keylog/pcap и файлы application content остаются чувствительными.
  Redact распознаёт перечисленные имена/URL, не произвольные секреты в телах.
  Неполный/ошибочный H1 framing не используется для угадывания следующей
  головы в теле; корректные production forward запросы проверены отдельно.
- Полный QUIC suite остаётся красным. На неизменённом16c5d922 повторены
  отсутствующий ConnectionState.CurveID в self integration, allocation
  assertion STREAM и data race в testutils/simnet TestMTUEnforcement.
  Изменённый QUIC package и HTTP3 race зелёные; долг F09 не закрыт.
  Исторический fhttp TestServer_MaxQueuedControlFrames также не закрывался.
- Новые pins локальные, push/публикация не выполнялись. Для независимого
  повторения нужны сохранённый file proxy или публикация соответствующих
  форков; один root checkout не делает pins публично доступными.
- Существующий untracked `go.work` указывает на прежние checkout форков
  (utls161481b, QUIC16c5d922) и сохранён. Для финального кандидата
  необходимо `GOWORK=off`; обычная workspace-сборка с этим старым файлом
  переопределяет новые pins. Игнорируемые ранее собранные бинарники тоже
  не считаются финальной сборкой; проверен отдельный бинарник из новых pins.
- Посторонние untracked-файлы сохранены и исключены из коммитов/прогонов.
  Изначально untracked AGENTS.md обновлён локально, целиком в git не добавлен.
