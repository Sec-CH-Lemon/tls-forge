# A8: явная основа кандидата capture

Завершена часть C04/F02B в API/CLI. Общая A8 ещё не принята: workflow,
GREASE и нативные профили Chrome156 трёх платформ проверяются отдельно.

До исправления сборщик терял данные основы: на сохранённом исходном дереве
156d99fa получено203 ключа вместо340. Исходный RED и архивы root/четырёх
форков сохранены. Прежнее предположение плана про close_notify=true в этой
точке не воспроизвелось: оба значения былиfalse; доказанный дефект — потеря
полной политики, а не это конкретное значение.

Теперь FromCapture требует полную явную schema4/engine1 основу, сохраняет
все неизмеренные ключи и правила генерации. Имя/UA/бренды не выбирают
поведение. CLI выбирает только явно поставляемую основу той же семьи/платформы
либо --policy-from; отсутствие/неверный major отклоняются до измерения.
Новые --policy-from и --provenance-dir описаны в README и документации API.
JSON с сохранением остаётся одним документом вstdout, прогресс идёт вstderr.

Отдельный provenance содержит SHA256 точных сохранённых байтов профиля,
канонические JSON-хеши основы/захвата, режим запуска и происхождение полей.
Контекстные наблюдения не превращаются в новые константы; неизмеренные
значения основы остаются inherited. Метаданные не исполняются как профиль;
выход через symlink проверен подos.Root.

Проверки: profile PASS11.195s,100% statements; целевые CLI сrace PASS55.585s;
фактический TLS/H1/H2 путь сrace PASS2.069s,4 одновременно живущие политики
закрытия после capture→Save→Load→Client.Do. Есть отрицательные проверки
отсутствующей основы, неверного major, подмены имени/UA, потери происхождения,
выхода метаданных за корень и несовместимых наблюдённых генераций.

Хеши исходных доказательств: [checks-a8-capture.json](checks-a8-capture.json).
Приватные оригиналы: captures/tls-forge-a8-20261029 в соседнем net-fp-server.
Унаследованная политика не получает нового browser-verdict; полный QA
модуля и workflow-интеграция выполняются следующими частями A8. Engine остаётся
единым неопубликованным1.0.0; профили заново не ретегируются.
