# A8: QPACK первого запроса определяется состоянием

Новый headed Chrome156.0.8078.74 замер показал оба состояния первого запроса:
без известной таблицы RIC=0 и при уже прочитанных SETTINGS динамический RIC.
Это не константа и не поле, которое можно исключить как «dynamic».

Закреплённый quiche a1628192cf32ba40d21e0dd80f485d68c24ff87a обновляет
вместимость кодировщика при OnSetting; EncodeHeaderList использует её без
искусственного пропуска первой секции. Engine уже реализует такую зависимость
через h3.qpack.encoder_warmup_sections=0: table.capacity=0 запрещает динамику
до фактического получения параметров. Новый механизм не нужен.

JSON155/macOS/Linux/Windows исправлен с1 на0 с отдельным происхождением;
новые156 кандидаты наследуют правило.155 не объявлен заново измеренным.
Старые байты и исходный source export сохранены. Правила ALPS и ограничения
peer blocked credit не меняются. Не введено ожидание peer SETTINGS в запросе.

Независимые native наблюдения:2×512 Chrome соединений на одном owned origin,
в каждой последовательности3GET. Первый динамический блок встречался378/512
и401/512; статический134/512 и111/512. Парный клиент сJSON0 показал оба
представления; доли и редкое позднее получение SETTINGS сохранены, а не
объявлены равными браузеру. Разная длительность подготовки запроса/обработки
SETTINGS остаётся границей сравнения. Independent pylsqpack0.3.23 декодирует
реальные блоки; его wheel/sdist SHA256 сохранены по версионной PyPI metadata.

Детерминированный wire control отдельно проверяет уже полученные и ещё
удерживаемые SETTINGS, JSON0/1, без ALPS.0 использует динамику в первом
известном состоянии;1 отличается. Неизвестная таблица даёт статический блок
в обоих случаях, запрос не ждёт peer SETTINGS. Три race-повтора проходят;
повтор после JSON-переноса и platform-provenance checks тоже принят.

Новый измерительный стенд дополнительно удерживает SETTINGS до второго и
третьего запроса. Две независимые Chrome серии каждого состояния и продуктовые
контроли проходят: исходные QPACK/encoder/control bytes сохраняются для
сравнения по состоянию. Это расширяет конечный witness; malformed/blocked
policy и полная неотличимость браузера этим не доказаны.

Предопределённая GREASE проверка исходной полной серии:512соединений,16бинов,
Pearson≤60, без требования уникальности. Chrome N:19.0/15.9375, клиент15.0/13.875.
Полная трёхплатформенная A8 приёмка и финальный QA ещё выполняются.
