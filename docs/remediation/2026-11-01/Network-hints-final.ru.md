# Network hints и итоговая сверка с Chrome156

Согласованный 1ноября ограниченный объём выполнен локально. Подтверждённые
существенные расхождения network hints устранены. В конечной матрице TLS/H1/H2,
выбранных H3/QPACK состояний и основных сценариев запросов расхождений не осталось.
Это конечная проверка конкретных сценариев, а не гарантия неотличимости от любого
Chrome при любых ответах сервера.

## Что исправлено

1. Chrome155/156 больше не повторяют сохранённые `RTT=100`, `Downlink=1.45`,
   `ECT=4g` как сетевую оценку для всех хостов. Hints рассчитываются из текущего
   состояния по JSON-политике: priors по фактическому типу сети, HTTP/transport
   наблюдения, состояние публикации, ограниченные истории/кэш, salt одного
   браузерного инстанса, host hash, кванты и пределы. Отдельная тройка
   `100/1.45/4g` может быть легальным результатом Chrome; дефектом был её
   неизменный повтор вместо правила генерации.
2. macOS Wi-Fi корректно распознаётся по `Hardware=AirPort`, даже когда системная
   запись имеет `Type=Ethernet`. Независимый oracle обнаружил неверный выбор
   проводного prior; сохранены исходный wire, RED-регрессия и GREEN после fix.
3. По умолчанию каждый Do владеет отдельными transport, TLS/session, cookies,
   origin opt-ins, кэшем, оценщиком и salt. Redirect/Critical-CH внутри одного Do
   сохраняют его состояние. Явный `client` scope использован только как контроль
   поведения нескольких запросов одного инстанса.

Значения и выбор поведения принадлежат JSON; движок реализует общие измерения,
парсеры, bounded state, I/O и синхронизацию. Нет dispatch по имени браузера/UA.
[Справочник политики и metadata](../../profile-behavior.md#network-hints-from-current-observations-unreleased-engine-1).

В девяти155/156 профилях, включая close_notify-варианты, включён `estimated`.
Двенадцать151–154 профилей сохраняют прежнее отсутствие hints. Все83 каталожные
записи явно выбирают `none`. Неизменяемые исходные SHA и21 производная связка
сохранены в provenance; прежним браузерам не приписана новая NQE-приёмка.
Сохранён explicit-only Migrate; Load/Save/Clone ничего не включают автоматически.
SDK/daemon проверяют дополнительные capabilities, включая замену процесса.

Проверено opt-in отсутствие/появление hints, cookies и Critical-CH, POST/формы,
redirects, фактический протокол и тело. RTT/downlink в общем request harness
сравниваются по его старому machine-value правилу; **их реальные значения
дополнительно проверяет отдельный независимый oracle**. Build/persona поля
сравниваются с явно выбранным профилем; raw156.76/156.80 значения сохранены.

HTTP/3 использует неизменённый maintained `observe` и независимый C ls-qpack.
Нормализованы только заранее объявленные generated GREASE поля. Полный
статистический analyzer не ослаблен и не объявлен пройденным на малой выборке.
Эта проверка потоков не означает равенство всей QUIC packetization/timing.

## Зависимости и доказательства

Опубликованы с отдельными разрешениями владельца:

- uTLS `2f8200b`: strict selector; оба gate по696 запусков.
- fhttp `fc7146a..bd9be71`: полные timestamps/body ownership; оба gate по1905.
- QUIC `ed643428`: реальные receive/RTT и H3 observations; оба gate по2606.
- tls-client `7aa8761`, `3b8dd33`: binding и отдельная test-only коррекция CONNECT
  peer; оба конечных gate по475,32 race-повтора proxy-теста.

Новых allowances/exclusions нет. Первый tls-client gate с неправильным peer
сохранён и не объявлен принятым. Все исходные setup-отказы также сохранены:
неверный HTTPS RR target, фоновые запросы Chrome, конфликт внешнего Seatbelt с
собственным sandbox Chrome и ранние ошибки подготовки окружения. Они отделены
от дефектов продукта. Конечный hint-замер блокирует постороннее разрешение имён;
NetLog подтверждает только loopback TCP attempts и actual116/1600/4G baseline.

Публичная сборка связана с протестированным срезом:374 linked packages,
1234 build files;185 Go-файлов root без `_test.go` совпадают. Единственная
разница в linked runtime — документирующий concurrency-комментарий tls-client.
Модули, версии, source archives и SHA сохранены; runtime замен не осталось.

Raw before/after, NSS secrets, полные логи и исходники находятся в игнорируемом
закрытом capsule `NETWORK-HINTS-FINAL-R24`:579 файлов,269307404 байта,
manifest SHA256 `dcb85e69bad01f27f053191221e149c4e5c3c83741e3388ed68935b0ec833e85`.
Все SHA повторно проверены; каталоги0700,файлы0600. Полные machine-readable
[результаты и границы](checks-network-hints-final.json).

## Оставшиеся ограничения

- Нативный текущий witness — macOS/Chrome156. Новая Linux/Windows browser/CI
  приёмка и исторические сборки здесь не заявляются.
- Не измерены все активные ответы сервера, долгоживущие процессы, физическая
  смена сети и passive OS notifier; полная process-wide NQE/aggregate-counter
  эквивалентность не реализована этой порцией. Они вне согласованного объёма.
- Профиль не заменяет TCP/IP-реализацию ядра ОС. Конечные выборки не доказывают
  RNG/distribution equivalence или универсальную неотличимость.
- Сохранены выбранные владельцем Chrome close_notify/ACK особенности и integral
  Downlink wire form; это не заявление о полном соблюдении всех RFC.

Первоначальный исследовательский A13 целиком не отмечается выполненным.
Согласованная ограниченная порция завершена; дальнейшее исследование этих
возможностей требует отдельной задачи. Root остаётся локальным: push и новый
native CI этим этапом не выполнялись.
