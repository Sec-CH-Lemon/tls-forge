# Срочные исправления после аудита 29 октября

Реализованы четыре срочных исправления. Общая приёмка форков остаётся открытой:
последний классификатор принимает 7 из 8 графов, QUIC production — красный.
Полный корневой race прошёл; повторный полный coverage — 100%.
Кандидат остаётся unpublished engine 1.0.0, schema 4, daemon 3.

## Что исправлено

- QUIC `856851d7`: существующий предел QPACK 16 МиБ применяется до выделения
  памяти для HEADERS/трейлеров и к декодированным статическим трейлерам.
  Режим без объявленного SETTINGS больше не снимает внутреннюю защиту.
- QUIC `abb06a60`, tls-client `a9f4f3e`, root `4755cf5`: явный H3 SETTINGS ID 6
  управляет приёмом независимо от H1 и priority. Проверены ноль, 1 МиБ и большое
  значение на настоящем QUIC control stream. JSON сохраняет исходный wire value;
  внутренний предел памяти остаётся конечным. Профильные данные не менялись.
- Root `4755cf5`: Peek тела сохраняет первую ошибку транспорта. До исправления
  безопасный отказ на повреждённом трейлере терялся и чтение ждало30 с таймаута.
  Контроль через Client.Get теперь немедленно возвращает ошибку HEADERS.
  Отдельный запечатанный replay исходной encoding.go с конечными зависимостями
  воспроизводит потерю ошибки: reads=2, error=nil; исправленная версия читает
  один раз и сохраняет исходную ошибку. Промежуточный исследовательский H3log
  не используется как доказательство точного бинарного/модульного равенства.
- Root `94a82fe`: x/net 0.62.0, x/crypto 0.58.0, x/sys 0.49.0, x/text 0.43.0;
  example/go и лицензии согласованы. GO-2026-6860 больше не достижим.
- Root `8413ea8`, `052d7df`, `1cdcc17`: гейт проверяет полный диагностический
  транскрипт. Новая ошибка внутри старого TestRequestWrite отвергается.
  Нормализация задана по полям: Go harness, корень снимка, loopback port,
  адрес резолвера в точном sandbox-denied DNS сообщении; у поддерживающего
  Framer trace — время, object ID и число одинаковых событий. Все разные
  поля кадров проверяются, счётчики остаются в частном trace_counts.
  Новые assertions и изменённые поля кадров по-прежнему отвергаются.

## Проверки и границы

Полные корневые проверки: race — 667,082 с; coverage повтор — 151,177 с,
11 317 блоков / 16 359 statements / 0 непокрытых. Первый coverage за 155,663 с упал на
TestWhenAStreamCancellationGoesIsTheProfilesToSay. По 100 повторов на исходном
и исправленном снимках прошли; причина не установлена. Исходный отказ сохранён.

форка под race прошёл до интеграции. Новые тесты не ослабляют прежние assertions.

классификация — 7/8 accepted; полные наборы сохраняют известные падения. QUIC production сначала
показал TestMITCorruptPackets/towards_the_client (deadline 1 с), затем
TestAStreamCancellationGoesWithTheClientsNextACKAsItsProfileSays (нет ACK
в ожидаемом пакете). Это не добавлено в исключения. Исходный QUIC MITM-тест
прошёл 20 изолированных повторов. Причина этих сбоев остаётся открытой F09/A11.

Node/Python с настоящим daemon: 10/10 каждый. Обычный go.work build,

собираются. Локальные fork pins ещё не доступны с публичного proxy.
Vet/lint/generated/docs/workflows прошли; гейт имеет 14 отрицательных и модульных контролей.

сообщение GO-2026-5932 об OpenPGP, который проект не импортирует.
